מורידים ומתקינים את סאמי

מורידים ומתקינים במחשב, לא בטלפון. סאמי עובד רק בלשונית Code באפליקציית Claude למחשב, לא בצ'אט הרגיל ולא ב-claude.ai בדפדפן. צריך בערך 2 GB פנויים בדיסק, ואינטרנט בהקמה ובתמלול הראשון.

1

מורידים את הקובץ

מורידים את Sammy.zip ושומרים אותו איפשהו שנוח למצוא. לא צריך לחלץ אותו.

⬇ להורדת סאמי
2

מתקינים ב-Claude Desktop

הכפתורים באפליקציה באנגלית, כי לקלוד אין ממשק בעברית: Plugins בחלק העליון של התפריט שבצד השמאלי (לא למטה, איפה שמופיע השם שלכם) ← Add (הכפתור השחור למעלה מימין) ← Upload plugin, ואז בוחרים את הקובץ שהורדתם. לא גוררים את הקובץ לתוך שיחה, כי ככה הוא רק מצורף ולא מותקן.

1

בתפריט שבצד השמאלי, בחלק העליון שלו, לוחצים Plugins. לא למטה, איפה שמופיע השם שלכם.

2

למעלה מימין לוחצים על הכפתור השחור Add, ובתפריט שנפתח בוחרים Upload plugin

3

לוחצים על browse ובוחרים את Sammy.zip. אחרי זה הכפתור Upload נדלק, ולוחצים עליו.

3

פותחים מחדש

סגירה מלאה של Claude Desktop (לא רק סגירת החלון - האפליקציה ממשיכה לרוץ ברקע גם אחרי שסוגרים חלון) ופתיחה מחדש. בלי הצעד הזה סאמי לא ייטען.

Windows

לחיצה ימנית על סמל Claude ליד השעון (שורת המשימות) ← Quit / Exit. לא נמצא שם? Task Manager ← מסמנים את Claude ← End task.

Mac

ה-X האדום סוגר רק את החלון, לא את האפליקציה. יציאה מלאה: Cmd + Q, או מתפריט Claude שבסרגל העליון ← Quit Claude.
