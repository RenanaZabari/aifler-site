Accessibility statement

Updated: October 7, 2026

This is an English translation of the Hebrew accessibility statement. If there is any difference between them, the Hebrew version applies.

We want everyone to be able to use the website, including people with disabilities. The website was built according to the Israeli Equal Rights for Persons with Disabilities (Service Accessibility Adjustments) Regulations, 2013, and according to Israeli Standard 5568, which is based on the WCAG 2.0 guidelines at level AA.

What we did on the website

  • The website is built with standard, well-organized code and clear headings, so screen readers can navigate it.
  • You can move around the whole website with the keyboard only. The element in focus is marked with a clear outline.
  • At the top of every page there's a "Skip to content" link, for keyboard and screen reader users.
  • The color contrast between text and background meets the standard's requirements.
  • You can enlarge the text in the browser (Ctrl and plus) without the content breaking.
  • The website adapts itself to phone, tablet and computer screens.
  • Images have alternative text, and purely decorative icons are hidden from screen readers.
  • There are no flashing animations, videos that start by themselves, or time limits on the website.

What isn't perfect yet

We made an effort for all the pages to be accessible. If you still found something that doesn't work, we'll be glad to hear about it and fix it.

Physical accessibility arrangements

AiFler has no office or place that receives the public. All service is given through the website, email, phone and WhatsApp.
