מתקינים ב-Claude Desktop

הכפתורים באפליקציה באנגלית, כי לקלוד אין ממשק בעברית: Plugins בחלק העליון של התפריט שבצד השמאלי (לא למטה, איפה שמופיע השם שלכם) ← Add (הכפתור השחור למעלה מימין) ← Upload plugin, ואז בוחרים את הקובץ שהורדתם. לא גוררים את הקובץ לתוך שיחה, כי ככה הוא רק מצורף ולא מותקן.

פותחים מחדש

סגירה מלאה של Claude Desktop (לא רק סגירת החלון - האפליקציה ממשיכה לרוץ ברקע גם אחרי שסוגרים חלון) ופתיחה מחדש, כדי שההתקנה תיכנס לתוקף.

Windows

לחיצה ימנית על סמל Claude ליד השעון (שורת המשימות) ← Quit / Exit. לא נמצא שם? Task Manager ← מסמנים את Claude ← End task.

Mac

ה-X האדום סוגר רק את החלון, לא את האפליקציה. יציאה מלאה: Cmd + Q, או מתפריט Claude שבסרגל העליון ← Quit Claude.

שיחה ראשונה

פותחים שיחה חדשה וכותבים "היי פני". היא תציג את עצמה, ותנחה אותך איך להתקדם.

צריך חשבון ChatGPT בתשלום (Plus ומעלה). פני נכנסת ל-ChatGPT דרך Skills, וזה פיצ'ר של מנוי בתשלום.

1

מורידים ומחלצים

⬇ להורדת פני ל-ChatGPT

מורידים את Penny-ChatGPT.zip ומחלצים אותו. בפנים יש תיקייה בשם skills עם 20 קבצים, קובץ לכל יכולת של פני.

2

מעלים את 20 היכולות

ב-ChatGPT: Plugins (בתפריט הצד) ← הלשונית Skills למעלה ← + ← Upload from your computer. בוחרים את כל 20 הקבצים ביחד: נכנסים לתיקייה skills, לוחצים Ctrl+A, וגוררים אותם לחלון ההעלאה.

קובץ מסומן "Invalid skill"?

בדרך כלל זה אומר שהוא כבר הותקן. אפשר להתעלם.

3

מומלץ: מחברים Google Drive

ככה פני זוכרת בין שיחות. Plugins ← מחפשים Google Drive ← Connect. יוצרים ב-Drive תיקייה ריקה לפני (למשל Penny), ובשיחה הראשונה, כשפני שואלת איפה לשמור, אומרים לה את שם התיקייה. בלי זה פני עובדת מצוין, רק שבסוף כל שיחה היא נותנת קובץ המשכיות להורדה, ומצרפים אותו בשיחה הבאה.
